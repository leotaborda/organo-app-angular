# Descrição

O **Organo** é uma aplicação web desenvolvida durante o curso "Angular 19: Estruture componentes com signals e controle de fluxo" da Alura. Ele foi projetado para ser uma ferramenta intuitiva e eficiente na organização de projetos, permitindo que você adicione, visualize e gerencie seus projetos de forma simples e agradável.

## Funcionalidades Principais

*   **Adicionar Projetos:** Crie novos projetos com informações essenciais como nome, imagem (URL) e time responsável.
*   **Visualização Dinâmica:** Os projetos são exibidos em cards organizados, proporcionando uma visão clara e agradável.
*   **Favoritar Projetos:** Destaque seus projetos mais importantes, marcando-os como favoritos para acesso rápido.
*   **Gerenciamento de Estado com Signals:** Utilizamos Signals do Angular para um gerenciamento de estado reativo e eficiente, otimizando a performance da aplicação.
*   **Estilização Condicional:** A diretiva `ngClass` foi utilizada para aplicar estilos dinamicamente, melhorando a experiência visual e a usabilidade.

## Tecnologias Utilizadas

*   **Angular 19:** A plataforma para construção de interfaces web modernas e escaláveis.
*   **Angular CLI:** A ferramenta de linha de comando para agilizar o desenvolvimento com Angular.
*   **TypeScript:** A linguagem de programação que adiciona tipagem estática ao JavaScript, melhorando a manutenção e a qualidade do código.
*   **HTML5:** A linguagem de marcação para estruturar o conteúdo da web.
*   **CSS3:** A linguagem de estilo para dar vida e beleza à interface do usuário.

## Como Executar o Projeto

Siga estas etapas para executar o Organo em seu ambiente local:

1.  **Clone o Repositório:**

    ```bash
    git clone [link do seu repositório]
    ```
2.  **Navegue até a Pasta do Projeto:**

    ```bash
    cd organo
    ```
3.  **Instale as Dependências:**

    ```bash
    npm install
    ```
4.  **Execute o Servidor de Desenvolvimento:**

    ```bash
    ng serve
    ```
5.  **Acesse no Navegador:**

    Abra seu navegador e acesse `http://localhost:4200/` para visualizar o Organo em ação.
